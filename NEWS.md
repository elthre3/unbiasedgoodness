# unbiasedgoodness 0.0.0.9001

## Breaking changes

* `gof_groupfs()` now takes data, `gof_groupfs(x, y, index, m, b, k, sigma,
  aicstop, ...)`, selects a model by forward stepwise and tests it against
  the forward stepwise enlargement to `max(ceiling(m * s + b), s + aicstop)`
  groups. The previous version tested against a user-supplied set of groups,
  which is undefined when that set makes the full model saturated (e.g. all
  unselected variables with p > n).
* `gof_RPtest()` no longer returns `pval_OLS_beta`, `pval_OLS_rev` or
  `pval_lasso_rev`, and gains `pval_lasso_beta` and the arguments `lambda`,
  `B` and `...`.

## Bug fixes

* `simulate_gof_instance()` and `simulate_gof()` ignored `m` and `b` and
  always used the defaults `m = 1.2`, `b = 5`. Earlier simulation results
  labelled `b = 10` were run with `b = 5`.
* `gof_groupfs()` with a single selected group used a zero projection for
  the null model, giving a wrong statistic and degrees of freedom. The
  residual degrees of freedom `df2` were one too small in all cases. The
  untruncated statistic now agrees with `anova()`.
* `gof_groupfs()` called `quadratic_coefficients()` and `quadratic_roots()`,
  which were not defined in the package.
* `pval_OLS_beta` duplicated `pval_OLS`: `RPtests::RPtest()` ignores
  `beta_est` when `resid_type = "OLS"`.
* `simulate_hdr()` ignored its `xtype`, `btype`, `permuted` and `x.par`
  arguments, did not stop its cluster, and was not reproducible.

## Other changes

* The forward stepwise code is vendored from selectiveInference 1.2.5 with
  small fixes (see `R/groupfs_vendored.R`); selectiveInference, purrr,
  foreach and doParallel are no longer dependencies.
* Simulations use `parallel` with L'Ecuyer random number streams and a
  `seed` argument.
* Long simulation vignettes are now pkgdown articles using precomputed
  results in `inst/extdata`, regenerated by the scripts in `data-raw/`. A
  short "Getting started" vignette was added.
* Real unit tests, updated GitHub Actions workflows, and a README.
